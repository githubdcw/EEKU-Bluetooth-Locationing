# Open Jupyter Notebook from GitHub in Google Colab

To run a Jupyter Notebook (`.ipynb`) file directly from GitHub in **Google Colab**, simply replace:

```text
github.com
```

with:

```text
githubtocolab.com
```

in the GitHub URL, then press **Enter**.

## Example

Original GitHub URL:

```text
https://github.com/githubdcw/EEKU-Bluetooth-Locationing/blob/main/ipynb/Dataset19_step1_load_cfo.ipynb
```

Change it to:

```text
https://githubtocolab.com/githubdcw/EEKU-Bluetooth-Locationing/blob/main/ipynb/Dataset19_step1_load_cfo.ipynb
```

The notebook will then open directly in **Google Colab**.
